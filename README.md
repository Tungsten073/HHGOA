# Hacker House Goa 2026 - Frame / ID Card Generator

Official shortlisting task project for **Hacker House Goa 2026**.

## Project Purpose
An interactive, high-performance web application that enables attendees, builders, speakers, and sponsors to design, customize, and export personalized social media frames, digital ID badges, and entry passes for Hacker House Goa 2026.

## Development Setup

### Prerequisites
- Node.js >= 18.x
- npm >= 9.x
- Git

### Quick Start (Once Next.js App is Initialized)
```bash
# Navigate to the isolated project directory
cd ~/Projects/HH-Goa-2026

# Install dependencies
npm install

# Run local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.
