# Hacker House Goa 2026 - Shortlisting Task Specification

## Task Overview
Build an interactive **Frame / ID Card Generator** web application for Hacker House Goa 2026.

## Objectives
- Allow users to upload a photo and edit it (zoom, crop, rotate, position).
- Provide customizable Hacker House Goa themes, track badges, and roles.
- Input personal details (Name, Designation, Twitter/GitHub handle, Track).
- Dynamically generate a QR code pointing to participant profiles or social links.
- Export high-resolution images (PNG/PDF) for social sharing and event entry badges.

## Isolation Policy
All codebase elements, configurations, scripts, and documentation must remain strictly isolated inside `~/Projects/HH-Goa-2026`.
